# Dustrivo 0.33 — Тихая вода

**Подписанный Release-APK выпущен с новым ключом по прямому запросу владельца.** `ru.rokiru.cargo`, versionCode 34, versionName 0.33, Android 8.0+, target SDK 35. [Скачать APK](https://raw.githubusercontent.com/Rokiru/onetime-bot/main/releases/Dustrivo-0.33.apk).

**Не обновляет 0.32: сертификат изменён.** Удаление прежней установки удалит её прогресс. Автоматического переноса данных через смену подписи нет. Для будущих обновлений 0.33 нужно сохранить новый ключ. [История подписи](../docs/release/signing-lineage.md).

Новый исходник значка из прошлого чата отсутствует; значок 0.32 сохранён. Игра остаётся офлайн, без рекламы, аналитики и новых разрешений.

## Изменения

- **Два лесных адреса**, ID 48: четыре ящика, два обязательных адреса, грязный подъём и короткие спуски; обычный рейс без срока. Штатный ROVER и RIVET проверены.
- **Тихая вода**, ID 49: цистерна на 900 л, обязательные 250 л в береговой резерв, минимум 500 л на базе. BRINE и DELTA проверены. Перед уступами нужно снижать ход, учитывая плеск воды.
- Обязательные адреса новых дорог не превращаются в выполненные после восьми секунд просрочки. Можно вернуться к ним. Прежние дороги сохраняют свои правила пропуска и штрафов.
- В существующей диспетчерской показаны реальные инструкции заказа, условия приёмки генератора, смысл педалей/пониженной передачи, название предыдущего заказа для открытия закрытой дороги. Карта получила обозначение подвесного моста и региональные цвета. Три раздела меню сохранены.
- Сохранённый рейс относится к конкретной карточке. При выборе другого заказа он не подменяет выбранную трассу; замена требует существующего диалога подтверждения. Отмена сохраняет поездку, подтверждение сохраняет выбранный срочный/обычный договор. На карточке сохранения показаны машина, режим и уровни из контрольной точки.
- В ленте гаража крупно показаны названия моделей. Подсказки объясняют постоянные улучшения, три слота оснастки, бесплатную перестановку купленных деталей и стиль. При нехватке монет показана недостающая сумма. Минимум 44 px для основных кнопок/фильтра, проверен экран 640×320 с отступами.
- Обучение генераторному рейсу объясняет актуальную задачу вместо прежнего текста про лесничество. Сравнение с механиком обозначено как призрак, а не срок заказа. Для машины без подходящего эталона не предлагается чужой силуэт.
- Звук мостов учитывает настоящие координаты текущей редакции дороги, а двигатель — плавный газ, 4L и семейство новых машин. Мокрый шум учитывает воду. Частота обновления аудиопараметров ограничена 30 Гц; завершившиеся короткие звуки освобождают узлы. Новых сетевых/аудиоресурсов и тяжёлых эффектов нет.
- Карьера, карты и сохранения учитывают 50 дорог / 150 звёзд. Новые личные рекорды используют существующий pace30-формат с новыми ID. Добавлены шесть настоящих заездов механика: три на каждую новую дорогу. Прежние 144 записи сохранены.
- В «Об игре» добавлены Sergey Kempinen, arturovich2k19@gmail.com и офлайн-копия политики конфиденциальности.
- Исправлена подготовка SDK: sdkmanager использует прокси и доверенный CA среды, как Gradle, без отключения TLS. Скрипт APK больше не создаёт другой debug-сертификат по умолчанию при отсутствии прежней подписи.
