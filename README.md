# Искра: Последний свет

Офлайн-игра для Android: арена на четыре минуты, управление одним пальцем и развитие между попытками. Веди Искру через восемь секторов и уничтожь двух Стражей.

## Версия 0.1.0

- Автоматическая стрельба; свободное движение и рывок с неуязвимостью.
- Три вида обычных врагов, два босса и зоны с предупреждением об ударе.
- Десять складывающихся усилений: расщепление, пробивание, спутники, лечение и другие.
- Энергетический импульс, серии уничтожений, счёт и рекорд.
- Постоянные улучшения в мастерской за заработанные осколки.
- Три сложности, обучение, пауза, синтезированные звуки, вибрация и уменьшение эффектов.
- Локальные сохранения. Нет Интернета, покупок, рекламы, аккаунтов и аналитики.

Это первая играбельная версия для проверки на устройствах, а не финальная публикация для RuStore.

Тестовый APK: [скачать 0.1.0](https://github.com/Rokiru/onetime-bot/raw/refs/heads/main/releases/iskra-last-light-0.1.0.apk). Подготовленные APK сохраняются в `releases/` вместе с SHA-256 для прямого скачивания через GitHub.

## Сборка APK в Linux x86-64

Нужны Python 3.12+, Node.js 18+ для тестов и доступ к официальным хранилищам Android, Java и Gradle.

```sh
python3 scripts/bootstrap.py
bash scripts/build-apk.sh
```

Скрипт устанавливает JDK 21.0.8, Android command-line tools 19.0, SDK 35, build-tools 35.0.0 и Gradle 8.13 в игнорируемую `.tools/`. Архивы проверяются по контрольным суммам официальных источников; SDK Manager проверяет пакеты SDK. Исходники и ключи не изменяются установкой. Повторная установка использует подготовленные инструменты.

`scripts/gradle.py` использует существующий сетевой прокси и доверенный сертификат среды, сохраняя проверку TLS. Кеши, служебные настройки и тестовый ключ подписи хранятся внутри `.tools/`.

Сборка запускает тесты движка, `assembleDebug`, Android Lint и проверку подписи APK. Результат: `artifacts/iskra-last-light-0.1.0.apk` и SHA-256 рядом с ним.

Android 8.0+ (API 26), target SDK 35. На устройстве требуется Android System WebView. Графика процедурная; ассеты и игровой код встроены в APK. Разрешение только `VIBRATE`.

## Проверка интерфейса

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory app/src/main/assets/game
# В другом терминале, из корня репозитория:
node tests/browser-smoke.js
```

Проверка требует Playwright и Chromium (`/usr/bin/chromium`), доступных в текущей облачной среде. Тесты проверяют настоящий touch-input через Chromium, паузу, звук, сохранения, награды и мастерскую на трёх размерах экрана. Скриншоты сохраняются в `artifacts/`. Для ручной проверки на компьютере: WASD/стрелки, пробел — рывок, Escape — пауза.

Тест полного прохождения движка использует увеличенное здоровье и урон, чтобы проверить все переходы и боссов детерминированно; он не подтверждает финальный баланс сложности.

## Перед публикацией в RuStore

1. Проверить APK на реальных устройствах: производительность, звук, мультитач, сворачивание и возвращение.
2. Провести игровые тесты и настроить сложность, темп прогрессии и разнообразие противников по результатам.
3. Выбрать и безопасно сохранить постоянный release-ключ. Тестовый debug-ключ для публикации не использовать.
4. Подготовить release-сборку, проверить актуальные требования RuStore, возрастной рейтинг, описание, иконку, скриншоты и сведения о данных.

Гарантировать коммерческий успех до проверки на игроках нельзя. Эта версия проверяет основной игровой цикл; дальнейшее развитие — новые арены, визуальное разнообразие и расширение комбинаций усилений.

## Структура

- `engine.js` — детерминированная симуляция, без платформенных зависимостей.
- `game.js` — отрисовка Canvas, touch-input, звук, UI и локальные сохранения.
- `MainActivity.java` — защищённый офлайн-хост Android, жизненный цикл и вибрация.
- `tests/` — тесты симуляции и функциональные проверки интерфейса.

Игра и её графика созданы для этого проекта. Старый проект удалён; его история Git сохранена.
