## С 0.33/code34 — новый ключ по прямому запросу владельца

После разъяснения, что новая подпись не обновит старую установку и удаление 0.32 удаляет локальный прогресс, владелец явно поручил: «Делай с новым ключом».

Пакет остаётся `ru.rokiru.cargo`. Новый публичный сертификат SHA-256:

`b491b005f0413264f6c7995ac7c80cb0d3e7236176b65f17cf2cd338a2d31f0a`

Субъект: `CN=Sergey Kempinen, O=Dustrivo`. RSA 3072, SHA256withRSA, PKCS12, срок 10000 дней с даты создания. Это собственный Release-ключ, не стандартный Android Debug.

**0.33 нельзя установить поверх 0.32 или более ранних выпусков.** Android отклонит обновление из-за разных сертификатов. Для установки с тем же пакетом потребуется удалить старую версию, что удаляет её сохранения. Автоматическая миграция подписи и прогресса не реализована и не заявляется. Не удаляйте старую игру, если её прогресс важен.

Дальнейшие версии должны использовать новый ключ для совместимых обновлений установленной 0.33. Скрипт сборки сверяет подпись с публичным `scripts/signing-certificate.sha256`; смена этого файла не создаёт новый ключ и не переносит доверие Android.

Приватный ключ и конфигурация хранятся только в игнорируемой `.tools/dustrivo-signing/`. Частная резервная копия подготовлена вне репозитория; владелец должен скачать её и сохранить отдельно от облачной среды. В публичные APK, исходники, Git и материалы RuStore ключ/пароли не входят. Скрипт сборки никогда сам не генерирует ключ.

Проверки совместимости игровых checkpoint-файлов остаются действительными при наличии файлов сохранения, но не означают возможность обновления через барьер подписи Android.
