# Проверка Dustrivo 0.30

Подписанный Release, package `ru.rokiru.cargo`, versionCode **31**. `bash scripts/build-apk.sh` завершился успешно: исторические физические тесты 0.18–0.29, новые pace30/ghost30, Android assembleRelease и lintRelease. Проверены оригинальный сертификат, отсутствие debuggable, CRC и точное совпадение каждого ассета APK с исходниками.

APK: **1059478 байт**. SHA-256: `cc739a0003d1d194f167c70bfa46c08188acce3ab0cab71a14299312f47365cd`.

- **48/48** контрактов пройдены через публичные педали/передачу/лебёдку, без улучшений машины, с полным грузом, целостностью 100%, чистыми секторами и без пробоя цистерны. Контрольное время **75.77–118.52 с**. Сокращены 45 маршрутов, 3 сюжетных используют прежнюю геометрию. Гребень не менялся.
- **17102** сравнений профиля защищённых блоков; проверены непрерывность соединений и привязка к сетке, сохранение количества/координат взаимодействий, глубина четырёх изменённых бродов. Восемь тёплых восстановлений с последующим сравнением траекторий. Некорректные или разорванные пары меток версии отвергаются.
- Пять подлинных сохранений 0.29 из архивной симуляции продолжаются без pace30; траектории и оплата точно сравнены со старой версией.
- **144** эталона получены настоящими чистыми заездами на штатных машинах. Проверены разные стратегии, ранжирование, финиш новой трассы и совместимость формата/личных рекордов.
- `CARGO_CHROME=/usr/bin/chromium node tests/verify-hub29.cjs`: 640×360, 800×360, 873×393, 960×432; три вкладки, сенсорная прокрутка, кнопки, эвакуация, сохранение и старый быстрый режим.
- `CARGO_CHROME=/usr/bin/chromium node tests/verify-pace-ui30.cjs`: 640×360 и 873×393; совпадение превью с настоящей дорогой/переправой, гараж/возврат, сохранение и продолжение новой трассы, прежние план и поездка 0.29, отдельные рекорды и призрак, однократная оплата и следующий рейс без старого брифинга. Ошибок JavaScript не обнаружено.
