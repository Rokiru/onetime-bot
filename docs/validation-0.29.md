# Проверка Dustrivo 0.29

Подписанный Release, Android package `ru.rokiru.cargo`, versionCode **30**. Android lint и сборка пройдены. Проверены оригинальная подпись, отсутствие debuggable, CRC и точное совпадение каждого упакованного ассета с исходниками.

SHA-256 APK: `fb1236237155d9dcb7e99cb1774db5b92106b9529cad6fd2f66e7522a7fda806`.

`bash scripts/build-apk.sh` завершил все физические проверки 0.18–0.28 и новые `verify-logistics29.cjs` / `verify-ghost29.cjs`. После финальных правок интерфейса повторены упаковка Release/lint и проверки APK; физическая модель осталась прежней.

- 48/48 новых контрактов пройдены водителем с открытыми педальными командами, штатной машиной и нулевыми улучшениями. Есть действующие промежуточные остановки, переправы, насос, буксировка и парковка на базе.
- 34 маршрута с добавленной вязкой зоной; остальные используют существующие мосты/броды. 38 дополнительных заключительных подъёмов; защищённые взаимодействия не сдвинуты.
- Реальные проезд точки и возврат задним ходом, истечение 8 секунд со штрафом, идеальная подача с ускоренной разгрузкой.
- Реальное падение на подвеску: целостность груза уменьшается, цистерна пробивается и постепенно теряет воду/массу, машина остаётся управляемой.
- 5 новых тёплых состояний плюс парковка/удар, ограничения эвакуации и некорректные состояния. 5 подлинных снимков 0.28 сравнены с архивной симуляцией: прежние траектории и выплаты сохранены.
- 150 эталонных записей проверены на формат, действительный финиш и ранжирование времени; старые и новые личные призраки раздельны.

`CARGO_CHROME=/usr/bin/chromium node tests/verify-hub29.cjs` пройден на **640×360, 800×360, 873×393, 960×432**. Проверены три вкладки, один CSS, список/план рейса, возврат из гаража, настоящая сенсорная прокрутка через touch-события Chromium, размеры и непересечение четырёх кнопок управления, переключение 4L, эвакуация, сохранение после неё, продолжение одним нажатием, разделение истории/Гребня. Отдельная проверка загружает подлинное сохранение быстрого режима 0.28 и продолжает его без новой метки/физики. Ошибок JavaScript не обнаружено.

Снимки интерфейса Chromium: [диспетчерская](screenshots29/dispatch.png), [гараж](screenshots29/garage.png), [приближение к остановке](screenshots29/approach.png).

Осторожный контрольный водитель прошёл маршруты за **105.4–208.9 секунд**. Это доказательство стратегии, не человеческий плейтест и не подтверждение цели 60–120 секунд для всех дорог. FPS, ощущения от управления пальцами, системные звук и вибрация на Poco F5 здесь не проверялись. В RuStore ничего не опубликовано.
