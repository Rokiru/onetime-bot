# Отрисовка Dustrivo 0.19

Восемь сценариев: среднее их медиан при движении камеры уменьшилось с **24.26 до 15.44 мс (36.4% меньше времени)**. Все сценарии улучшились. Это сравнительная нагрузка Canvas в облачном Chromium, **не FPS Android или POCO F5**.

## Методика

Один Headless Chromium, CSS-экран 873×393, DPR устройства 2.75, качество «Авто». Обе версии используют одинаковый буфер 1440×648: снижение разрешения не применялось. Версия 0.18 взята из предыдущего коммита; 0.19 — из текущих ассетов. Другие тесты и Android-сборка на время измерения завершены.

Физические тела заморожены. Для неподвижной камеры — прогрев и медиана пяти серий по 20 отрисовок. Для движущейся — 120 кадров, сдвиг на 0.08 м за кадр (4.8 м/с при 60 кадрах); высота камеры следует профилю. Каждый кадр включает всю сцену и чтение одного пикселя, принудительно завершающее растеризацию. Readback меняет поведение Canvas; числа нельзя пересчитывать в ожидаемый FPS телефона. Звук выключен, затраты физики, DOM и Android WebView этим сравнением не измеряются.

## Воспроизведение

```sh
mkdir -p /tmp/dustrivo-018
git archive 75bd5a794bc8c9d5de70f311789f77e09783e966 game/assets | tar -x -C /tmp/dustrivo-018
CARGO_CHROME=/usr/bin/chromium node tests/benchmark19.cjs
```

Скрипт запускает локальные HTTP-серверы только для измерений и пишет `renderer19-results.json`. Другой Chromium можно указать через `CARGO_CHROME`, другую папку ассетов 0.18 — через `CARGO_BASELINE`. Перед повторением нужно остановить другие тяжёлые процессы.

## Отдельно проверено

- При подаче 60/90/120 callbacks за секунду отрисовка ограничена 60 кадрами, время и результат физического торможения совпадают. Пауза не меняет физику; меню/пауза ограничены 30 кадрами. Цель 60 не является обещанием достигнутого FPS устройства.
- UI проверен на 640×320, 747×336, 873×393, 915×412 и 1000×500, DPR 2.75, с вырезом слева/справа и нижним отступом: целая выбранная строка, читаемые/прокручиваемые условия, постоянная кнопка, настоящий вертикальный свайп, отсутствие перекрытия вкладок.
- У APK versionCode 20, подпись совпадает с 0.18; CRC и все ассеты проверены, Android Lint завершён без ошибок.

На реальном POCO F5 FPS, длительные рывки и нагрев ещё не измерены. Измерения не заменяют такую проверку.
